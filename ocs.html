Edita tu web

Qué es

Una herramienta para editar tu web visualmente.

En una frase: abres la herramienta en el navegador, le das acceso a tu repositorio, y tu web aparece ahí para que la edites como si fuera un programa de diseño.

Sin instalar nada. Sin programas externos. Todo en el navegador.

El problema · Parte 1

Editar una web estática es más difícil de lo que debería.

  • Tienes que abrir el editor de código.
  • Buscar el archivo correcto entre todos.
  • Encontrar la parte exacta que quieres cambiar.
  • Escribir a mano con cuidado de no romper nada.
  • Subir el cambio y esperar a que se actualice.

Todo eso por cambiar una palabra.

El problema · Parte 2

Y esto afecta a los dos lados.

Al desarrollador

  • Le llegan mensajes por cambios pequeños.
  • Tiene que parar lo que hace para atenderlos.
  • No puede dar acceso al repositorio sin riesgos.

A quien usa la web

  • No puede cambiar su propio sitio.
  • Depende de alguien para todo.
  • Su única alternativa es montar algo más complejo.

Paso 1

Conectar con tu repositorio.

Le das a la herramienta una llave de acceso a tu GitHub. Es como una contraseña temporal que solo sirve para ese repositorio.

  • La llave se guarda solo en tu navegador, no en un servidor.
  • La próxima vez que entres, ya estás dentro. No hay que repetirla.
  • Si cierras sesión, se borra.
Paso 2

Se traen las páginas de tu web.

La herramienta lee tu repositorio y muestra una lista con todas las páginas que tiene tu sitio. Solo las páginas visibles, nada de configuración ni código interno.

Paso 3

Tu web aparece tal cual es.

La ves con sus colores, sus fuentes, sus imágenes y sus menús. Exactamente como se ve en internet.

Lo único distinto es que ahora puedes tocarla.

Paso 4

Editas como si fuera un programa de diseño.

  • Haces clic en algo y se selecciona.
  • Lo arrastras y se mueve.
  • Tiras de las esquinas y cambia de tamaño.
  • Haces doble clic en un texto y lo escribes.
  • Cambias colores, tamaños y animaciones desde un panel.
Paso 5

Guardas y ya está en internet.

La herramienta sube los cambios a tu repositorio automáticamente. No tienes que hacer nada más. En segundos, tu web está actualizada.

  • Cada cambio que guardas queda como una versión en tu GitHub.
  • Si algo sale mal, puedes volver a la versión anterior.
  • No se pierde historial de nada.
Guardar · Por dentro

Un solo envío hace todo.

La herramienta le manda a GitHub el contenido nuevo de la página y GitHub se encarga del resto.

// Así viaja tu cambio a GitHub PUT /repos/{usuario}/{repo}/contents/{página} { "message": "Update index.html via OpenCanvas Studio", "content": "<contenido nuevo de la página>", "branch": "main" } → listo · GitHub Pages se actualiza solo

Diferencia

Comparado con otros editores.

  • ✕ Necesitan servidores o servicios externos
  • ✕ No puedes mover ni redimensionar
OpenCanvas Studio
  • ✓ Editas viendo tu web tal cual es
  • ✓ No hay nada que configurar
  • ✓ No necesita servidores
  • ✓ Funciona con cualquier web que ya tengas

No reemplaza a un CMS. Es una forma distinta de editar.

Casos de uso

Cuándo tiene sentido usarlo.

Agencias y freelancers

  • Entregar el sitio con editor incluido.
  • Dejar de recibir mensajes por cambios pequeños.

Landings y sitios de una página

  • No hace falta un sistema complejo para una sola página.
  • Cambios frecuentes de textos, precios o banners.

Portafolios personales

  • Actualizar trabajos desde el navegador.
  • Sin depender de nadie para cada cambio.
